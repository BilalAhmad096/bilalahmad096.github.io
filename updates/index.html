Released mintorian on PyPI

mintorian is an open-source Python framework for power system optimisation. Version 0.1.0 models a network of buses, lines, generators and loads, solves DC power flow, and solves DC optimal power flow for least-cost dispatch with locational marginal prices. Install it with pip install mintorian. View mintorian on PyPI.
